### T0.2 目录骨架 + build.sh + run.sh
创建目录：`src/main/java/dev/cppviz/`、`src/main/resources/web/`、`tracer/`、`samples/`

`build.sh`：
```bash
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")"
JAVA_HOME="${JAVA_HOME:-/opt/homebrew/opt/openjdk@21}"
rm -rf out/classes && mkdir -p out/classes
find src/main/java -name '*.java' > out/sources.txt
"$JAVA_HOME/bin/javac" -encoding UTF-8 -d out/classes @out/sources.txt
cp -R src/main/resources/. out/classes/
echo "build ok"
```

`run.sh`：先执行 build.sh，再 `"$JAVA_HOME/bin/java" -cp out/classes dev.cppviz.Main "$@"`

- 验收：`./build.sh` 退出码 0，`out/classes` 下存在 .class 文件。

### T0.3 Main 起 HttpServer
`src/main/java/dev/cppviz/Main.java`：
- 只绑 `127.0.0.1`，端口用 `0`（随机分配），启动后向 stdout 打印一行：`VIZ_PORT=<实际端口>`
- `GET /` → 从 classpath 读 `/web/index.html` 返回，`Content-Type: text/html; charset=utf-8`
- 其他路径返回 404；所有响应 UTF-8
- 用 `java.awt.Desktop` 打开默认浏览器，失败不影响主流程（打印一行提示即可）
- `web/index.html` 先放一个 `<h1>Hello viz</h1>`

- 验收：启动后 `curl -s http://127.0.0.1:<VIZ_PORT>/` 输出包含 `Hello`。

### T0.4 lldb 探针（最小 tracer.py）—— 最关键的一步
`samples/basic.cpp`：
```cpp
#include <cstdio>
int main() {
    int a = 1;
    int b = a + 2;
    printf("%d\n", b);
    return 0;
}
```

`tracer/tracer.py`（运行在 lldb 的内嵌 Python 里，被 `command script import` 时自动 bootstrap）：
- 从环境变量读：`VIZ_SRC`（源文件路径）、`VIZ_MAX_STEPS`（默认 5000）
- 只对 `VIZ_SRC` 指向的源文件的**每一行**创建断点；该行没有代码导致建不上就跳过并删除该断点（`bp.GetNumLocations() == 0`）
- 断点回调里：发一行 `VIZ {json}` 到 stdout 并 flush，然后 **`return False`**（表示不停下、继续执行）
- 行格式：`VIZ {"t":"step","n":<序号>,"line":<行号>,"vars":{"a":"1","b":"3"}}`
- 开头发 `VIZ {"t":"meta","src":"...","engine":"lldb"}`
- 结尾发 `VIZ {"t":"end","steps":<总数>,"reason":"ok"}`；步数超过 `VIZ_MAX_STEPS` 时先 Kill 进程再发 `{"t":"end",...,"reason":"truncated"}`
- **必须**在运行前执行 `settings set target.output-path <某个文件>`，把被测程序的 printf 隔离出去，**绝不能让它污染 stdout**
- 取变量值用 `SBFrame.GetVariables(True, True, False, True)`，值走 `SBValue.GetValue()` 或 `GetSummary()`

运行方式：
```bash
clang++ -std=c++17 -g -O0 -fno-omit-frame-pointer samples/basic.cpp -o out/a.out
VIZ_SRC=samples/basic.cpp VIZ_MAX_STEPS=1000 lldb -b \
  -o "settings set target.output-path out/a.out.txt" \
  -o "command script import tracer/tracer.py" \
  -o run -- out/a.out
```
- 验收：输出中 `grep -c '^VIZ'` ≥ 3，且最后一条是 `{"t":"end"`。
- 若 `grep -c '^VIZ'` 为 0，按这个顺序排查并把结论写进 DEVLOG §6：
  1. `command script import` 的路径是否可解析（优先用绝对路径）
  2. `-o` 顺序是否 import 在 run 之前（断点必须在 run 之前建好）
  3. Python 输出是否没 flush（每次写后 `sys.stdout.flush()`）

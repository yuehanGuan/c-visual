## 任务 A1：tracer 补地址（tracer/tracer.py）
新增字段，不改已有字段：
- 每个变量节点增加 `addr`（十六进制字符串，例 `"0x16fdff2c8"`）
- `seq` 增加 `dataAddr`（首元素地址；取不到则省略）
- 新增 `kind:"ptr"`：`{"kind":"ptr","type":"int *","addr":"...","target":"0x602010","value":"0x602010"}`
  判断依据：`vtype.IsPointerType()`
- 每步最外层增加 `heap` 数组，元素形如
  `{"addr":"0x602010","type":"int","count":4,"capacity":4,"items":["10","20","30"]}`
  来源：`seq` 节点的 dataAddr 与 capacity（vector 的元素在堆上，这点必须画出来）

## 任务 A2：SVG 内存图（新增 src/main/resources/web/memory.js，并在 index.html 引入）
- `Memory.render(container, step, prevStep, addrIndex)` 输出 SVG
- 三个纵向区域带：栈 / 堆 /（无堆内容时隐藏堆区）。每区标题右侧显示地址范围
- 栈帧：圆角矩形 + 标题栏（函数名 + 栈深），内部每个变量一行「名字 / 类型 / 值 / 地址」
- 数组与 vector 缓冲：连续格子，格子上方是下标；`capacity > size` 的尾格用虚线
- 指针箭头：从变量行右侧画一条二次贝塞尔曲线到目标块左边缘，末端带箭头；
  目标地址解析不到时，终点画在堆区右上角并标 `?`
- 变化高亮：与上一步比较，值变化的格子/行加 `.changed`（黄色描边 + 短暂淡出）
- 当前帧：accent 描边
- 递归：帧按 depth 从小到大自上而下排列，压栈/出栈用 CSS transform 过渡（≤200ms）
- 地址显示：默认显示简写（如 `…c8`），鼠标悬停显示完整十六进制
